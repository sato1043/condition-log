# 日ごとに印を選び、カレンダーに出す

## 目的

カレンダーで見つけたい日を、本人が選んだ印で見分けられるようにする（TASK0031 の
カレンダーの見方の上に重ねる）。

## 目標

- 今日のページで、その日の印を ●■◀▶―×♥♠♣♦ の 10 種から 1 つ選べる
- 選んだ印を、カレンダーのその日に、記録の印とは別に出す

## 非目標

- 1 日に 2 つ以上の印を付けない（TASK0031 の裁定記録）
- カレンダーの見方そのもの（切り替え・記録の印・診察の日・メジャー）を扱わない
  （TASK0031 が持つ）
- 印から体調を判定しない。アプリは印に医療上の意味を持たせない（憲章の非目標）

## 問題

- 印を DB に持つ。毎日の記録の表（`daily_logs`）へ列を足すと、スキーマの版を上げ、移行の
  段を書き、ER 図を直す（CONTRIBUTING「開発のコマンド」）。TASK0017（体温）も表を変える
  ので、先に入る方が版を上げ、後の方がその次の版を取る
- 選んだ印を外して、印の無い日へ戻す操作。段と同じく、選んだ印をもう一度押すと外す形が
  考えられる
- 過去の日のページ（◀▶ で開く日）でも選べるか
- 印だけを選んだ日を、「記録の入力がある日」（TASK0031 の記録の印）と TASK0028 の
  「何も付けていない日」に数えるか
- 選べる印に ● があり、記録の印と同じ日に並ぶ。見分け方は TASK0031 と一緒に決める
- 印の ◀ ▶ は、今日のページの日を移るボタン（◀▶）と同じ形で、取り違えうる
- 置く部品と位置。今日のページの縦は、最大の文字サイズですでに苦しい（TASK0028 の
  問題）。10 種を並べるか、ダイアログで選ぶか
- 読み上げ。記号の読み名（● を「黒丸」と読むなど）を ARB に持つか。TalkBack が記号を
  どう読むかは端末の音声エンジンで異なりうる
- 記録の書き出し（TASK0010）に印を含める
- 印の色。地に対して 3:1 以上にする（憲章・見え方記述）
