# GUI 部品の形と文字の大きさを Material の既定へ寄せる

## 目的

GUI 部品の形と文字の大きさを Material の既定へ寄せ、独自の値を、既定では憲章の目標
（文字サイズ・片手操作）を割る箇所に限る。既定に寄せると、見え方記述とテーマが持つ
独自の値と、それを確かめるテストが減る。

## 目標

- R9 を、部品の文字（ボタンの名前・欄の名前・欄の補足）は Material がその部品に当てる
  既定の段で示す形へ改める。記録・見出し・自作の部品（段）の文字は、今のとおり主要な
  情報を本文の大きい段以上で示す（見え方層）
- 欄の名前（V89）と欄の補足（V90）の大きさ、ボタンの文字の段を、Material の既定へ
  戻す。名前を打つ前から枠の上に出すこと、補足を欄の外に置き読み上げで欄の案内として
  読ませ全文を折り返すことは保つ（見え方層）
- 下端のナビゲーションの高さ（V95）・名前（V96）・アイコン（V98）と欄の間の空き
  （V99）を、今の値と既定（V99 は欄の名前を戻した後の候補）を実機で撮って並べ、裁定
  した値にする（見え方層）
- 既定へ戻した値は見え方記述から消し、残す値には既定では割る理由か裁定を添える。
  文字の段の表の用途をコードの使い方と一致させる（見え方層）
- テーマ・部品・テストを改めた値へ揃える（見え方層）
- 改めた値を名指す完了した作業書（TASK0002・TASK0013）の到達基準と概要設計に、
  改めたことの注記を足す（見え方層）

## 非目標

- 色（TASK0029 が受け持つ）
- 部品を足すこと・画面の構成を変えること
- 文字の大きさを OS の設定に任せる規則（R3）そのものを変えること
- ダイアログの組み立て（`app_dialog.dart`・`pick_visit_day.dart`）。形の値を持たず、
  背景を読み上げから外すため（憲章の目標）と、日付を選ぶダイアログが iOS の最大の
  文字ではみ出さないため（R3）に Material の組み立てを写している
- 目標に挙げた値の外の形。文字に合わせて 1.5 倍まで大きくなるアイコン
  （`icon_size.dart`）と、気を付けることの追加ボタンの高さ 56 dp（当時の編集の画面に
  在った。TASK0026 が足す欄を作り直し、この指定は無くなった）

## 問題

- 独自の値は、どれも大きな文字の設定での裁定から来ている。ナビゲーションは最大の文字で
  記録の欄を潰さないため（TASK0013）、欄の名前は主要な情報を本文の大きい段以上で示す
  ため（R9）である。既定へ戻すと、この裁定の前提が崩れないかを、最大の文字の設定の実機で
  測り直す必要がある（テストは最大の文字の 1 行を決められない）
- ナビゲーションの 3 値は規則を割らない。ユーザーが実機の撮影を見比べて選んだ値で
  （TASK0013 の裁定）、撮らずに既定へ戻すとその裁定を覆す
    - 既定の名前は `labelMedium`（12）を OS の設定で 1.3 倍まで拡大する。名前を固定する
      今の形は、長押しのツールチップの文字を固定の前の倍率で補う組み立てを持つ
- ボタンは約 25 か所のうち、気を付けることの「編集」（体調のページの見出しの行。今の
  `precaution_mark_list.dart`）だけが
  `titleMedium` で、残りは既定の `labelLarge`（14）である。見え方記述は `labelLarge` を
  「使わない（ボタンは `titleMedium` で示す）」とし、R9 は操作の名前を本文の大きい段
  以上と定めるので、宣言とコードが食い違っている
- 欄の名前が中身にかからないことは、テストのフォントの字面で測る。字面は、行の上下の
  空きを等分し（Material の段の既定）、字の高さを文字の大きさと置いて求める。テストの
  フォントでは厳密だが、日本語の代わりのフォントは字面の高さが違いうる
- 欄の間の空き（V99）は、Material に既定が無い。欄の名前が枠の上へはみ出す分から決めた
  値なので、名前を既定の大きさへ戻した後に測り直す
- iOS の最大の文字（AX5）は、自動テストの倍率でしか確かめられない。iOS の実機で欄の
  名前・欄の補足（`bodySmall` の折り返し）・ボタン・ナビゲーションを確かめ、欄の名前の
  字面が中身の字面にかからないことを日本語のフォントで見る（Mac で作業するとき）

## 概要設計

- **R9 の改め方**: R7 が色について「部品へは Material が当てる既定の役割のまま色を
  取る」と定めるのと同じ形にする。部品の文字は既定の段で示し、記録・見出し・自作の
  部品（段）の文字に「主要な情報は本文の大きい段（V76）以上、小さい段は補足に限る」を
  残す。V76 は後者が引くので残す
    - 分け方は文字の種類で決める。部品の中に出る記録（診察の一覧の行の抜き出し。
      `ListTile` の副題の既定は `bodyMedium`）は、記録として本文の大きい段で示す
    - 部品の文字は、Material の部品が描く文字（ボタン・欄の名前と補足・ダイアログ・
      メニュー・ツールチップ）を挙げて閉じる。欄の名前に添える件数は名前の一部とする
- **欄の名前**: `fieldDecoration` を欄の名前の唯一の入口として残し、打つ前から枠の上に
  出す指定（`FloatingLabelBehavior.always`）と、読み上げの名前（`spokenName`）を保つ。
  名前の拡大（`_FieldName` の 1/0.75 倍と OS の倍率の二重掛けの回避）と、名前の大きさに
  依る上の余白を外し、Material の既定に任せる
    - TASK0002 が `always` を選んだ理由（枠の中央に座る名前が中身の無いボタンに見える）
      は、塗らない枠になった今も成り立つので残す
- **欄の補足**: `HelpedField` の文字を `bodySmall` にする。置き場所・案内としての
  読み上げ・字下げ・折り返しは保つ。Material の `helperText` は欄の後の別の文として
  読むので使わない（折り返しは `helperMaxLines` で足りるが、読む順は変えられない）
- **ボタン**: 気を付けることの「編集」から `titleMedium` の指定を外す。鉛筆と文字の間は
  Material の既定（8 dp）へ戻る（TASK0029 で受容した間隔の変化が解ける）
- **撮影の見比べ**: 欄とボタンを既定へ寄せたビルドで、テスト用の端末（SM_A253C）の
  `font_scale` 1.0 と 2.0 で今日のページ・診察のページ・設定を撮る。同じ撮影で次の
  候補を並べる
    - ナビゲーション: 今（68 dp・32 dp・`bodyMedium` の固定）と既定（80 dp・24 dp・

      割らない）
    - 欄の間の空き: 32 dp と 16 dp（画面のほかの空き）。名前が枠の上へはみ出す分を測って

- **裁定の反映**: ナビゲーションを既定へ戻すなら、`navigationBarTheme` の `height` と
