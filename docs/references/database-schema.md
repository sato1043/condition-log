# DB の表と関係（ER 図）

アプリが端末に持つ DB（SQLite）の表と、表どうしの参照を示します。正本はスキーマの
書き出し（`drift_schemas/app_database/`）の最も大きい版です。

`test/data/database_schema_doc_test.dart` が、このドキュメントを書き出しと照らします。
照らすのは、下の「スキーマの版」の行と、「表」の節の表の集合・列の並び・各列の名前・型・
NULL・主キー・既定値・参照です。制約（CHECK）・意味の欄・参照の図・app_settings の
キーの一覧は照らしません。これらは表の写しなので、スキーマを変えるコミットで一緒に
直します。

スキーマの版: 4

## 参照の図

矢印は、列が指す先の表の列を示します。点線の矢印は外部キーを持たない参照（app_settings の
値が指す先）です。

```
+------------------+  precaution_id   +-------------+
| precaution_marks | ---------------> | precautions |
+------------------+        id        +-------------+

+--------+  care_provider_id   +----------------+
| visits | ------------------> | care_providers |
+--------+         id          +----------------+
                                       ^
+--------------+  value of             :
| app_settings | . . . . . . . . . . . .
+--------------+  usual_care_provider  id

+------------+
| daily_logs |
+------------+
```

## 表

列の表の読み方:

- 型: DB のファイルが持つ SQL の型です。drift の型（`bool`・`dateTime`）は意味の欄に
  書きます
- NULL: 「可」は NULL を持てる列です
- 主キー: 主キーを成す列に、主キーの中の順番を書きます
- 既定値・参照: 書き出しの SQL のとおりに書きます。参照は `表.列` です
- 制約: CHECK を意味で書きます。式の写しは書きません

### daily_logs

1 日に 1 行の記録です。

| 列 | 型 | NULL | 主キー | 既定値 | 参照 | 制約 | 意味 |
|---|---|---|---|---|---|---|---|
| day | TEXT | 不可 | 1 | | | 日付の形（`YYYY-MM-DD`） | 記録の日 |
| overall | INTEGER | 可 | | | | 1〜5 | 全体の体調。5 が良い側。NULL は記録なし |
| pain | INTEGER | 可 | | | | 1〜5 | 痛み。同上 |
| fatigue | INTEGER | 可 | | | | 1〜5 | だるさ。同上 |
| sleep | INTEGER | 可 | | | | 1〜5 | 睡眠。同上 |
| appetite | INTEGER | 可 | | | | 1〜5 | 食欲。同上 |
| mood | INTEGER | 可 | | | | 1〜5 | 気分。同上 |
| memo | TEXT | 可 | | | | | メモ |
| updated_at | INTEGER | 不可 | | | | | 最後に書いた時刻（`dateTime`）。いまは読まない |

### precautions

気を付けることです。項目は、名前と気を付け方（控える・続ける）を持ちます。消さずに
使わないにします。

| 列 | 型 | NULL | 主キー | 既定値 | 参照 | 制約 | 意味 |
|---|---|---|---|---|---|---|---|
| id | INTEGER | 不可 | 1 | | | 自動採番 | |
| name | TEXT | 不可 | | | | 半角の空白だけでない名前 | 名前 |
| manner | TEXT | 不可 | | | | `refrain` か `keepUp` | 気を付け方。`refrain` は控える、`keepUp` は続ける |
| sort_order | INTEGER | 不可 | | | | | 並びの順 |
| in_use | INTEGER | 不可 | | `1` | | 0 か 1 | 使うか（`bool`） |

表の制約: 名前と気を付け方の組は一意です。使う項目と使っていない項目を合わせて、同じ
組の項目を 2 つ持ちません。既にある組を足す・直すときの扱いは、リポジトリ
（`lib/features/daily_log/data/drift_precaution_repository.dart`）が決めます。

### precaution_marks

気を付けることができた日の印です。行があれば、その日にできたこと（控える項目は控えた
こと、続ける項目は続けたこと）を示します。行が無い日は、できなかった日と付けていない
日を分けません。

| 列 | 型 | NULL | 主キー | 既定値 | 参照 | 制約 | 意味 |
|---|---|---|---|---|---|---|---|
| day | TEXT | 不可 | 1 | | | 日付の形（`YYYY-MM-DD`） | できた日 |
| precaution_id | INTEGER | 不可 | 2 | | `precautions.id` | | できた項目 |

### app_settings

設定です。1 つの設定が 1 行で、キーは「app_settings のキー」にあります。

| 列 | 型 | NULL | 主キー | 既定値 | 参照 | 制約 | 意味 |
|---|---|---|---|---|---|---|---|
| key | TEXT | 不可 | 1 | | | | 設定の名前 |
| value | TEXT | 不可 | | | | | 設定の値（文字列で持つ） |

### visits

診察です。日付が今日か今日より後なら、予定の診察です。1 日に 2 件以上を持てるので、
`day` は一意ではありません。

| 列 | 型 | NULL | 主キー | 既定値 | 参照 | 制約 | 意味 |
|---|---|---|---|---|---|---|---|
| id | INTEGER | 不可 | 1 | | | 自動採番 | |
| day | TEXT | 不可 | | | | 日付の形（`YYYY-MM-DD`） | 診察の日 |
| to_ask | TEXT | 可 | | | | | 診察の前に書く、医師に聞くこと |
| heard | TEXT | 可 | | | | | 診察の後に書く、医師から聞いたこと |
| updated_at | INTEGER | 不可 | | | | | 最後に書いた時刻（`dateTime`）。いまは読まない |
| care_provider_id | INTEGER | 可 | | | `care_providers.id` | | 診察を受けた受診先。NULL は選んでいない |

### care_providers

受診先です。病院・診療科・医師名の 3 つの名前を持ちます。消さずに使わないにするので、
診察からの参照は切れません。

| 列 | 型 | NULL | 主キー | 既定値 | 参照 | 制約 | 意味 |
|---|---|---|---|---|---|---|---|
| id | INTEGER | 不可 | 1 | | | 自動採番 | |
| hospital | TEXT | 可 | | | | NULL か、半角の空白だけでない名前 | 病院 |
| department | TEXT | 可 | | | | 同上 | 診療科 |
| doctor | TEXT | 可 | | | | 同上 | 医師名 |
| in_use | INTEGER | 不可 | | `1` | | 0 か 1 | 使うか（`bool`） |
| updated_at | INTEGER | 不可 | | | | | 最後に書いた時刻（`dateTime`）。いまは読まない |

表の制約: 3 つの名前のどれかを持つ。SQLite の `trim` は半角の空白（U+0020）だけを除く
ので、ほかの空白（全角の空白・タブ）だけの名前は、表でなくドメインの規則
（`lib/domain/name.dart`）が拒みます。

## app_settings のキー

行が無いキーは、既定の値として働きます。

| キー | 値の形 | 値が指す先 | 行が無いとき |
|---|---|---|---|
| `day_start_hour` | 0〜23 の整数（10 進の文字列） | なし | 0 時 |
| `usual_care_provider` | 受診先の id（10 進の文字列） | `care_providers.id`（外部キーなし） | いつもの受診先は無し |
| `about_app_shown` | `1`（値は読まず、行の有無だけで決める） | なし | 初めて起動したときの「このアプリについて」をまだ示していない |

`usual_care_provider` は外部キーを持たないので、書き出しと読み込み（TASK0010）で id を
付け替えるときは、この値も付け替えます。指す受診先が無い・使っていない・値が数でない
ときは、いつもの受診先は無しとして働きます。

`about_app_shown` は、書き出しと読み込み（TASK0010）で移しません。書き出しを読み込んだ
端末では、初めて起動したときに 1 度示します（TASK0024）。OS の端末間の移行（Android 12
以上）と iOS のバックアップからの復元は DB ごと移すので、この行も移り、移った先では
示しません。
